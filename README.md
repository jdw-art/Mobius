# DevOps一体化平台

一个基于React的DevOps项目管理平台，提供项目全生命周期管理功能。

## 功能特性

### 1. 项目管理页面
- 项目列表展示（项目编号、项目名称、项目类型、PM、进展、计划交付时间）
- 项目搜索和筛选
- 项目状态管理
- 响应式表格设计

### 2. 项目详情页面
- 项目基本信息展示
- 流程状态图（创建、设计、开发、测试、预发布、生产发布、合并主干）
- 项目进度统计
- 项目动态记录
- 团队成员管理
- 多标签页管理（概况、任务、需求、应用、产品验收、测试缺陷、评审、文档、风险）

## 技术栈

- **前端框架**: React 18
- **UI组件库**: Ant Design 5
- **路由管理**: React Router 6
- **样式**: CSS3 + 自定义样式
- **图标**: Ant Design Icons


## 页面说明

### 项目管理页面 (/)
- 展示用户参与的所有项目
- 支持按项目类型筛选
- 支持搜索项目名称、编号或PM
- 点击项目名称可进入项目详情

### 项目详情页面 (/project/:id)
- 项目头部：显示项目编号、名称、状态、类型等基本信息
- 概况标签页：包含项目计划时间、流程状态图、进度统计、动态记录、团队成员
- 其他标签页：任务、需求、应用、产品验收、测试缺陷、评审、文档、风险管理

## 流程状态图

项目流程包含以下阶段：
1. **创建** → 2. **设计** → 3. **开发** → 4. **测试** → 5. **预发布** → 6. **生产发布** → 7. **合并主干**

每个阶段之间的关键节点：
- 设计→开发：设计评审
- 开发→测试：代码扫描、提测、冒烟测试、代码评审、单元测试
- 测试→预发布：测试完成、产品验收
- 预发布→生产发布：预发验证
- 生产发布→合并主干：生产验证

## 自定义样式

项目使用自定义CSS类名，主要样式包括：
- `.workflow-container`: 流程状态图容器
- `.workflow-step`: 流程步骤样式
- `.workflow-node`: 流程节点样式
- `.progress-section`: 进度统计区域
- `.content-split`: 左右分栏布局
- `.activity-item`: 动态记录项样式
- `.team-member`: 团队成员样式
