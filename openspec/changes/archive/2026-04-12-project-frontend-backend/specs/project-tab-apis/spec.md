## ADDED Requirements

### Requirement: Requirements tab fetches from API
The system SHALL fetch requirements from `/api/v1/projects/{id}/requirements`.

#### Scenario: User navigates to requirements tab
- **WHEN** user navigates to project requirements tab
- **THEN** system SHALL fetch from `/api/v1/projects/{id}/requirements`
